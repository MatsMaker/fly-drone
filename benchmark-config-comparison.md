# Конфігурації бенчмарку: «до» і «після» оптимізації

Маршрут бенчмарку однаковий для всіх прогонів: клавіша B, 60 с по прямій зі швидкістю 35 м/с на висоті 60 м над рельєфом, напрямок (1, 0, 1). Заміри робляться на білді Windows, а не в редакторі.

## Змінені параметри

| Крок | Параметр | Де змінюється | До (`before`) | Після | Що це дає |
|---|---|---|---|---|---|
| threads | Use Background Threads | `WorldSettings` | вимк. | ✓ | генерація тайлів переходить у фонові потоки, зникають фризи 100+ мс при перетині меж тайлів |
| threads | Heightmap Resolution | `WorldSettings` | 513 | 257 | у 4 рази менше даних на тайл; крок сітки ~3.9 м достатній для польоту |
| terrain | Pixel Error | `WorldSettings` | 1 | 6 | менше трикутників рельєфу на відстані |
| terrain | Basemap Distance | `WorldSettings` | 1000 | 300 | далекі ділянки малюються однією запеченою текстурою замість змішування 4 шарів |
| terrain | Draw Instanced | `WorldSettings` | вимк. | вимк. ¹ | **свідомо не змінювався** — див. примітку 1 |
| trees-fog | Tree Distance | `WorldSettings` | 2000 | 700 | дерева за туманом не малюються |
| trees-fog | Enable GPU Instancing | матеріали `TreeTrunk`, `TreeCrown` | вимк. | ✓ | однакові дерева малюються пачками, а не кожне окремим draw call |
| trees-fog | Far Clip Plane | `CM_Chase`, `CM_FPV` → Lens | 5000 | 2500 | камера не рендерить те, що все одно сховане туманом |
| trees-fog | Fog | Lighting → Environment | вимк. | ✓ (Linear, 800–2200 м) | ховає межу завантаженої зони (5×5 км навколо дрона) |
| shadows | Max Distance | URP-ассет (`PC_RPAsset`) → Shadows | 500 | 150 | тіні рахуються лише там, де їх видно |

## Незмінні параметри

Однакові в усіх прогонах, щоб порівняння було чесним:

| Параметр | Значення |
|---|---|
| Load Radius / Unload Radius | 2 / 3 тайли |
| Max Concurrent Jobs | 2 |
| Pool Size | 8 |
| Alphamap Resolution | 256 |
| Tile Size / World Size | 1000 м / 8×8 тайлів |
| Seed | 1337 |
| Shader Stripping → Instancing Variants | Strip Unused |
| Shadow Cascade Count | без змін |

## Примітки

1. **Draw Instanced для terrain свідомо не вмикався.** У білді з terrain, створеним у рантаймі, ця опція спершу прибирала рельєф повністю: Unity вирізав інстансинг-варіанти шейдера terrain, бо на момент білду в сцені немає жодного terrain. Глобальне налаштування Instancing Variants = Keep All повертало рельєф, але разом з увімкненим Draw Instanced у білді зникали тіні. Для ~25 одночасно завантажених тайлів внесок Draw Instanced невеликий, тому пріоритет віддано коректній картинці. Наступний крок — розібратися з варіантами шейдера (наприклад, увімкнути інстансинг точково для матеріалу terrain замість глобального Keep All).

2. **Порядок кроків має значення.** Оптимізації вмикаються групами й накопичуються: кожен наступний прогін включає всі попередні зміни. Так видно внесок кожної групи окремо.

3. **Матовість terrain і дерев** (гладкість шарів terrain, Smoothness матеріалів дерев) — візуальні зміни, на продуктивність практично не впливають і в таблицю не входять.

4. **Тіні:** якщо редактор і білд використовують різні рівні якості (Project Settings → Quality), Max Distance змінюється в ассеті того рівня, який позначений за замовчуванням для платформи PC.
